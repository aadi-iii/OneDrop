# 🩸 OneDrop

> **Saving Lives, One Drop at a Time.**

OneDrop is a modern blood donation platform designed to connect donors, receivers, and blood banks through a simple, responsive, and user-friendly web application.

The platform aims to simplify the blood donation process by providing a centralized system where users can register, request blood, manage donations, and access important information through dedicated dashboards.

---

## ✨ Current Features

- 🔐 Secure Firebase Authentication
- 👤 Donor Dashboard
- 🩸 Receiver Dashboard
- 🛡️ Admin Dashboard
- 📋 Blood Request Management
- 👥 User Management
- 🌙 Dark & Light Theme
- 📱 Fully Responsive Design
- ⚡ Smooth UI & Animations
- 🔥 Cloud Firestore Integration
